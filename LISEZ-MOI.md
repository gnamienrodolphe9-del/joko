# JOKO V1 (corrigé)
1. Extraire ce dossier dans un NOUVEAU dossier (ex. Bureau\joko-v1-corrige).
2. Copier votre ancien fichier .env dans ce dossier (ou copier .env.example en .env et le remplir).
3. npm install
4. node server.js
Attendu dans le terminal : "Base de données connectée ✔" puis "JOKO prêt sur http://localhost:3000".
